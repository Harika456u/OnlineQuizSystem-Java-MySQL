# Online Quiz System
## Project Description
The Online Quiz System is a web-based application developed to conduct online quizzes efficiently. This project allows users to attend quizzes, answer multiple-choice questions, and view their scores instantly. The system is designed with a user-friendly interface and database connectivity for storing quiz-related data.

The project was developed using frontend and backend technologies including HTML, CSS, JavaScript, Java, and MySQL.

## Database Setup

1. Open XAMPP
2. Start Apache and MySQL
3. Open phpMyAdmin
4. Create database:
   quizdb
5. Import the SQL file from the database folder

---

## How to Run the Project

1. Open the project in VS Code
2. Start XAMPP server
3. Run MySQL database
4. Open frontend files using Live Server
5. Compile Java backend files
6. Execute Java files using Command Prompt
